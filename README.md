# আমার আয়-ব্যয় — Offline PWA

## GitHub Pages-এ প্রকাশ
1. GitHub-এ একটি **Public** repository তৈরি করুন, যেমন `amar-ay-bay`।
2. এই ZIP-এর সব ফাইল ও `icons` ফোল্ডারের ভেতরের ফাইলগুলো repository-র root-এ আপলোড করুন। `index.html` root-এ থাকতে হবে।
3. **Settings → Pages** খুলুন।
4. **Deploy from a branch** নির্বাচন করুন, branch `main`, folder `/(root)` দিয়ে **Save** করুন।
5. প্রকাশিত `https://USERNAME.github.io/amar-ay-bay/` লিংক Chrome-এ খুলুন।
6. প্রথমবার অনলাইনে থাকা অবস্থায় পেজটি লোড হতে দিন, তারপর Chrome-এর `⋮` মেনু → **Install app** বা **Add to Home screen** চাপুন।
7. ইনস্টল হওয়ার পর একবার অনলাইনে অ্যাপ খুলে রাখুন। এরপর অ্যাপের মূল ফাইলগুলো ক্যাশে থাকায় ইন্টারনেট ছাড়াই চালু হবে।

## গুরুত্বপূর্ণ
- GitHub Pages-এর HTTPS-এ Service Worker কাজ করে।
- আয়-ব্যয়ের তথ্য এই ফোন/ব্রাউজারের local storage-এ থাকে; অন্য ডিভাইসে নিজে থেকে সিঙ্ক হয় না।
- ব্রাউজারের site data মুছলে তথ্য হারাতে পারে। অ্যাপের **ব্যাকআপ** বোতাম দিয়ে JSON ফাইল সংরক্ষণ করুন।
- নতুন সংস্করণ আপলোড করলে অনলাইনে অ্যাপ খুলে কিছুক্ষণ অপেক্ষা করুন; প্রয়োজন হলে বন্ধ করে আবার চালু করুন।
